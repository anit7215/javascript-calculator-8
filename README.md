# javascript-calculator-precourse
# 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.
## 기능 목록
- 입력 기능
    - [ ] 사용자로부터 구분자와 양수로 구성된 문자열을 입력받는다.
    - @woowacourse/mission-utils의 Console.readLineAsync() 사용

- 입력값 검증
    - [ ] 숫자가 아닌 값이 포함되어 있으면 Error 발생
    - [ ] 음수 입력된 경우 Error 발생
    - [ ] 커스텀 구분자 형식 오류 시 Error 발생

- 문자열 파싱
    - [ ] 기본 구분자 처리
        - 쉼표(,)또는 콜론(:)을 기준으로 분리
    - [ ] 커스텀 구분자 처리
        - 문자열 앞부분의 "//"와 "\n" 사이의 문자를 구분자로 지정
    - [ ] 빈 문자열("")일 경우 0 반환

- 덧셈 기능
    - [ ] 파싱한 숫자들을 모두 더한다.

- 출력 기능
    - [ ] 결과를 출력한다. 
        `결과 : {합}`
